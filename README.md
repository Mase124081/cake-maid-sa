# Cake Maid SA

This repository contains a premium online storefront and business website for Cake Maid SA, a custom confectionery brand in Pretoria.

## Features
- Premium luxury bakery design
- Modern landing page with clear conversion-focused CTA
- Product showcase and service highlights
- Contact, location and social links
- Responsive layout for mobile and desktop
- Framer Motion animations
- Tailwind CSS styling

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Production build

```bash
npm run build
npm run start
```
